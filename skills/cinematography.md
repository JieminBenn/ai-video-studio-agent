# Cinematography Skill

Purpose: make shots filmable, editable, and emotionally motivated.

Use this structure:

- Framing: wide, medium, close-up, insert, over-the-shoulder, profile, or extreme close-up with a clear reason.
- Lens feel: wide spatial pressure, normal perspective, portrait compression, macro detail, or deep-focus geography.
- Camera movement: push-in, pull-back, track, drift, handheld, pan, tilt, orbit, or locked-off only when the stillness is intentional.
- Blocking: where the subject starts, where they move, what enters/exits frame, and what changes visibly.
- Layered motion: foreground, subject, and background should each have a reason to be alive.
- Light: motivated source, contrast, color temperature, direction, and how it changes across the beat.
- Edit target: start and end poses should connect naturally to neighboring shots.

Avoid generic motion, unclear screen direction, random camera movement, static photo-like video, and shots that do not visibly advance the beat.
