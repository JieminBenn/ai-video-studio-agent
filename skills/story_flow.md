# Story Flow Skill

Purpose: make each shot advance the story so neighboring keyframes never repeat the same beat.

A shot ADVANCES when it delivers at least one new piece of story information the audience did
not have one shot ago:
- a new action outcome (something visibly changed as a result of the last beat),
- a changed emotional state (a face/body turn the audience has not seen yet),
- a revelation (new object, place, person, or fact enters the story),
- a spatial or temporal move (new location, new time, new distance/scale),
- a shifted relationship (the standing between characters changed).

A shot is REDUNDANT when its story information is already fully contained in a neighboring
shot — it only re-frames, re-establishes, or restates a beat the audience already has.

Apply this:
- Every shot must name what is NEW about it versus the shot before it.
- If two adjacent shots carry the same new information, merge them into one or cut one.
- Prefer forward motion: setup -> escalation -> choice -> consequence, each beat distinct.
- Do not re-establish a space the audience already understands unless something in it changed.

This is about story information, not camera framing. Two shots can be framed differently and
still be redundant if the audience learns nothing new; that is the failure to avoid.

## Dramaturgy first (story before pixels)
A run of distinct shots is not yet a story. Before the shots serve, the scene needs dramatic
shape — lock this first, then let the shots carry it:
- **Objective + obstacle.** Someone in the scene wants something and something is in the way.
  If neither is legible, the scene is inert no matter how it is framed.
- **Escalation.** Each beat raises stakes, tightens pressure, or narrows options — never idles.
- **A turn.** The scene changes something: a decision, a reveal, a reversal, a shift in the
  standing between characters. A scene that ends where it began has not happened.
- **Consequence carries forward.** The turn's result becomes the next scene's starting state,
  so momentum compounds instead of resetting.
Map the shots to that shape: setup → pressure → turn → consequence, each beat earning its place.
