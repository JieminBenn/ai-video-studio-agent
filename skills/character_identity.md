# Character Identity Skill

Purpose: create stable character anchors that can survive many image and video generations.

Use this structure:

- Canonical face: face shape, eye/brow shape, nose, mouth, skin details, age read, and any signature marks.
- Canonical body: height impression, build, posture, proportions, hands, gait, and silhouette.
- Hair and grooming: style, color, volume, parting, flyaways, facial hair if present.
- Wardrobe lock: exact outfit layers, fabric, trim, closures, shoes, accessories, and wear state.
- Material and color palette: fabric behavior, metal/cloth/leather details, and 3-6 stable colors.
- Turnaround sheet: front, profile, and back views of the same person with matched proportions and wardrobe.
- Expression sheet: neutral plus several readable emotions using the same face, hair, and wardrobe.
- Detail panels: face close-up, hands, jewelry/props, garment seams, pattern, and material swatches.
- Do rules: what must remain identical in every shot.
- Do-not rules: what must not drift, simplify, age-shift, or change between shots.

Visual reference sheets should be clean, organized, production-design oriented, and readable at a glance.
Avoid collage chaos, inconsistent faces, random outfit variants, decorative text, and multiple incompatible designs.
